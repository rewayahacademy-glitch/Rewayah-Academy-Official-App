# 00 - Contradictions et arbitrages

Date : 24/09/2026. Consolidation des contradictions relevées par `C01` à `C11` et le manifeste visuel, plus les divergences entre rapports vérifiées dans le code (section E).

Ordre d'arbitrage du mandat §2 : **(1)** demande explicite du directeur (le mandat, dont le complément « observation » corrige la partie principale) ; **(2)** sécurité et contrats d'accès existants ; **(3)** high-fi ; **(4)** décisions métier canoniques les plus récentes (`docs/current` : `08` > `00` > `01`-`07` ; décisions directeur Classes V2 `ARB`/`CXC` hors `docs/current`) ; **(5)** Bible, jetons, composants ; **(6)** archives et anciennes captures.

Colonne « Point directeur » : **Oui (Pn)** seulement quand l'arbitrage change réellement le produit ou relève d'une action que le coordinateur ne peut pas décider ; **Info** pour une alerte hors arbitrage ; **Non** sinon (le coordinateur applique l'ordre du mandat, décision réversible).
