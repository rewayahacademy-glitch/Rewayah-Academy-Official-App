# Où trouver les images (captures d'écran)

Écrit pour le directeur, sans jargon.

Chaque partie de l'application a son propre dossier d'images, à l'intérieur
de `05_recette`. Le nom du dossier est celui de la partie du travail :

- `05_recette\A\captures` — Bienvenue, connexion, inscription (dossier tuteur)
- `05_recette\B\captures` — Foyer (les enfants, les appareils partagés)
- `05_recette\c\captures` — Accueil, la classe, le catalogue de classes
- `05_recette\D\captures` — Appareils : caméra/QR, code de connexion
- `05_recette\e\captures` — Mon compte, historique des séances
- `05_recette\o\captures` — Observation (salle d'observation d'une séance)
- `05_recette\demo\captures` — Mode démonstration (voir aussi
  `05_recette\demo\OU_TROUVER_LA_DEMO.md`)

Dans chaque dossier, les fichiers vont par paires ou par quatre : même écran,
en format téléphone (390x844) et en format ordinateur (1440x900), en thème
clair et en thème sombre. Le nom du fichier dit l'écran (par exemple
`foyer_contenu_390x844@3_light.png` = l'écran Foyer, taille téléphone, thème
clair).

Certains dossiers ont aussi une « planche » : une image qui met la maquette
d'origine et le résultat réel côte à côte, pour comparer d'un coup d'œil
(fichiers qui contiennent `_contre_` ou `planche` dans leur nom).

Ces images sont dans le dossier de pilotage sur cet ordinateur
(`C:\RA\pilotage\05_recette\...`) et sur GitHub, branche
`pilotage/tuteur-v1`, même chemin. Elles ne sont pas dans l'application
elle-même : ce sont des preuves de vérification, pas un contenu que
l'application affiche.
