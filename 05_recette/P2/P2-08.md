   La planche `D\captures\scanner_lecture_entier_contre_M3.png` montre le

   une page à carte, pas un plein cadre caméra. Déjà noté R-08 dans
   `D\REVUE.md:31` et non corrigé depuis (le fichier n'apparaît pas dans les
   diffs `f799ade`/RAPPORT.md comme régénéré pour cette raison).
   Correction proposée : mettre l'aperçu caméra bord à bord sur téléphone
   (le disque retour et « Saisir le code » se superposent au cadre, comme
