# Où trouver le mode démonstration

Écrit pour le directeur, sans jargon.

- Le bouton s'appelle **« Essayer la démonstration »**. Il est sur le premier
  écran de l'application (l'écran de bienvenue) et sur l'écran de connexion.
- Il n'existe **que dans la version d'essai** (l'aperçu de recette), jamais
  dans la version publiée pour les familles. C'est voulu : des données
  inventées ne doivent jamais apparaître devant un vrai parent.
- Aujourd'hui, aucune version d'essai n'est en ligne avec les derniers
  travaux : la mise en ligne passe par une étape que le poste B n'a pas le
  droit de faire seul (déploiement). Dès qu'un aperçu est déployé, le bouton
  y est visible.
- En attendant, les images de la démonstration sont dans
  `05_recette\demo\captures\` (même dossier que ce fichier).
- Dans la démonstration, un bandeau « Démonstration » est affiché en haut de
  chaque écran, et il est aussi lu à voix haute par les lecteurs d'écran.
