# L1-07 - `profiles.gender` n'est plus modifiable par son titulaire

Vague 1 (sécurité). Dépend de L1-09. Indépendant des autres lots. Petit lot.

## 1. But et pourquoi (P1-5, rapport section 4.2 ; `0088_kyc_super_admin_gender_exception.sql`)

Le genre du lecteur commande quelles pièces d'identité un administrateur peut voir (`read_kyc_documents`, cloisonnement de `0088`). La policy `profiles_self_update` (`id = auth.uid()`) laisse chacun modifier sa propre ligne, et le trigger `guard_profile_privileged_columns` (`0084:135`) ne protège que `role`, `household_id`, `account_status`, `access_until`. Un administrateur ou un enseignant change donc son genre par REST et traverse le cloisonnement.

## 2. Critère de réussite

C'est fini quand :

1. une migration horodatée redéfinit `guard_profile_privileged_columns()` en ajoutant `or old.gender is distinct from new.gender` à la liste des colonnes gardées, et en mettant le message à jour : `'seul un admin modifie rôle, foyer, statut, accès ou genre'` ;
2. le scénario `supabase/tests/scenarios_af_l1_07_genre_protege.sql` prouve : sous jeton `teacher`, `update public.profiles set gender = <autre> where id = auth.uid()` lève `insufficient_privilege` ; sous jeton `admin` valide, la même mise à jour sur un autre profil réussit ; sous jeton `teacher`, `update ... set first_name = 'X' where id = auth.uid()` réussit encore ;
3. le parcours d'inscription, qui écrit le genre à la création (`creer_profil_inscription(... p_gender gender ...)`, DEFINER, propriétaire `postgres`), continue de passer : `scenarios_etape4.sql` vert.

## 7. Pièges connus

- Le trigger est `security invoker` : sous `set local role authenticated`, `current_user` vaut `authenticated`, la garde s'applique ; sous `postgres` elle ne s'applique pas. C'est le comportement voulu, le scénario ne teste pas `postgres`.
- `profiles_self_update` est aussi dans la liste des 50 policies sans `app_account_valid` ? Non (elle n'a pas de rôle). Elle n'est pas touchée par L1-08. Ne pas l'étendre ici.
- Un `update` qui ne change pas le genre (`set gender = gender`) passe : `is distinct from` est faux. Normal.
