# L1-10 - MFA du contrôleur (TOTP et garde `aal2`) - conditionnel à l'arbitrage A-02

Vague 1, lot conditionnel : ne commence qu'après la décision écrite du directeur sur A-02 (rapport section 7). Sans décision, ce lot n'existe pas.

## 1. But et pourquoi (matrice X-04, S-10 ; doc maître 28.2 : le contrôleur observe des enfants, un mot de passe volé ne doit pas suffire)

Rien n'existe : `supabase/config.toml:310-312` a `[auth.mfa.totp] enroll_enabled = false, verify_enabled = false`, aucune garde `aal2` dans `rejoindre_observation` ni dans les RPC de mission, aucun écran d'enrôlement.

## 2. Critère de réussite

C'est fini quand :

1. `supabase/config.toml` active `enroll_enabled = true` et `verify_enabled = true` pour TOTP (local et, par le directeur, dans le tableau Supabase de STAGING) ;
2. une migration horodatée ajoute une fonction `public.app_aal()` qui lit `auth.jwt() ->> 'aal'`, et une garde dans `rejoindre_observation(uuid)` et dans les RPC de mission du contrôleur (liste à établir : `grep -n "controller" supabase/migrations/*.sql | grep -i "create or replace function"`) : `if public.app_role() = 'controller' and coalesce(public.app_aal(), 'aal1') <> 'aal2' then raise exception 'seconde étape de connexion requise' using errcode = 'insufficient_privilege'; end if;` ;
3. le scénario `supabase/tests/scenarios_af_l1_10_mfa_controleur.sql` prouve qu'un jeton `controller` avec `aal = 'aal1'` est refusé par `rejoindre_observation` et accepté avec `aal = 'aal2'` ; qu'un `admin` en `aal1` n'est pas concerné (sauf décision contraire) ;
4. côté application (lot frontal séparé, Claude) : à la première connexion d'un contrôleur sans facteur enrôlé, un écran d'enrôlement (QR, code à six chiffres) avant toute navigation ; libellés FR « Protégez votre compte de contrôleur » / AR « احمِ حساب المراقب الخاص بك », « Code à six chiffres » / « رمز من ستة أرقام » ; états loading, content, empty (pas d'application d'authentification : lien d'aide), error, offline ; tests widget 390 et 1440 ; la redirection vit dans `lib/core/router/redirection.dart` (lecture d'une capacité `mfaRequise`, jamais du rôle).
