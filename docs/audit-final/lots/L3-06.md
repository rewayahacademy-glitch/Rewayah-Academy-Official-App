## 2. Critère de réussite

C'est fini quand :

1. une migration horodatée `revoke execute ... from authenticated, anon, agent_ro, service_role` sur les quatre fonctions retirées (pas de `drop` : l'historique des migrations et des scénarios les cite) ; un `comment on function` qui dit « remplacée par X, audit final L3-06 » ;
2. le client n'appelle que les fonctions gardées : si `service_groupes.dart` envoie les six paramètres courts, il passe aux huit (fuseau et couleur : lire d'où l'écran les tient ; si l'écran n'a pas de couleur, envoyer `null` si la signature longue l'accepte, sinon section 8) ;
3. `scenarios_b18_security_definer.sql` (qui vérifie que `anon` n'a pas EXECUTE sur les deux surcharges) reste vert : il teste `anon`, qui n'a déjà rien ; les appels sous `authenticated` aux surcharges courtes dans ce scénario (lignes 30 à 45) doivent être adaptés : attendre 42501 au lieu de `creation de groupe reservee a l'administration` ;
4. la liste blanche L1-09 est mise à jour (quatre lignes de moins) ;
5. `scenarios_af_l3_06_rpc_uniques.sql` prouve 42501 pour chaque fonction retirée sous un jeton `admin` valide, et le succès de la fonction gardée ;
6. rejeu complet vert ; `flutter test test/core/admin test/core/offres` vert.

## 7. Pièges connus

- PostgREST choisit la surcharge selon les clés du JSON envoyé : un client qui envoie six clés appelle la courte. Après le revoke, il recevra 42501 : d'où l'étape 2 avant la migration.
- `revoke` sur une surcharge exige la signature complète (`public.creer_groupe(uuid,text,text,smallint,smallint,smallint)`), sinon « function name is not unique ».
- Les fonctions gardées ne bougent pas : aucun md5 d'allowlist à recalculer.
- Un scénario ancien (`etape*`, `adm*`) qui appelle une surcharge courte sous `authenticated` devient rouge : l'adapter à la longue, en le disant.

## 8. Quand s'arrêter et demander

- La signature longue exige une couleur et l'écran n'en propose pas : s'arrêter (petite décision d'écran : couleur par défaut ou choix).
- Une fonction Edge appelle une fonction retirée : s'arrêter.
