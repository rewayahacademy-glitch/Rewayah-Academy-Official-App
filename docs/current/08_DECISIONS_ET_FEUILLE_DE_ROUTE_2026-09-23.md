## 4. Architecture d'exécution après C0 : une tranche verticale à la fois
Une tranche verticale suit une action humaine réelle entre rôles et couches : `écran famille -> autorisation/RLS -> commande métier -> données -> écran admin/enseignant -> séance -> résultat visible -> test réel`. Les rôles déterminent les vues et permissions ; ils ne deviennent pas des applications ou backends parallèles. On peut répartir les écrans entre agents seulement après figer les contrats communs et un intégrateur propriétaire des migrations, routes, thème et auth.

| Tranche | Parcours démontrable et sortie | Dépendance/gate |
|---|---|---|
| V0 Vérité produit | Supprimer démo en production, corriger fausse mention d'enregistrement, documenter mode guidé et état des salles | Avant la première famille réelle |
| V1 Première classe | Admin crée classe avec enseignant, capacité, jours/durée/fuseau ; tuteur voit catalogue réel et choisit ; inscription transactionnelle ; enseignant voit le même groupe ; élève voit sa séance | CORE24 : corriger gate PostgreSQL et audit, prouver RLS/concurrence/DST |
| V2 Premier cours | Même famille rejoint `/salle` avec enseignant ; LiveKit, Coran natif dirigé, reconnexion, présence, traitement des visiteurs | Une seule salle et un seul contrat temps réel ; aucune UI factice |
| V3 Continuité | Enseignant valide cahier, travail et reprise ; élève/tuteur voient la suite ; groupe suit la prochaine occurrence | Brancher D/F/H au parcours vivant, ne pas dupliquer leurs services |
| V4 Exploitation | Admin contrôle incidents, absentéisme, remplacements, accès et paiements manuels ; équipe teste plusieurs familles et fuseaux | Preuves de sécurité, cohérence et support opérationnel |
| V5 Livraison web | Diagnostic CI réel, Git connecté à Vercel, build de `main` automatique prouvé par SHA et URL | Ne pas confondre CLI manuelle et déclenchement Git |
| V6 Après MVP | Curriculum fin, finance versionnée, credits/payouts, KPI et Advisor selon `07` | Lots distincts et arbitrages publiés |

Chaque tranche modifie le minimum de surfaces, possède un responsable de contrat, un parcours E2E démontré avec identité réelle de test et une preuve d'autorisation négative. Interdiction de qualifier `vert` une tranche parce que ses tests unitaires passent : 1 762 tests peuvent réussir avec des modules non raccordés.
