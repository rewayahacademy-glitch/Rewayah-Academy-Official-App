# Source pour le secrétaire : les annonces de 2026 (WhatsApp)

Reçu du directeur le 16/11/2026 : l'archive de ses annonces de janvier à octobre 2026
(environ trente messages, en français, signés RA_STAFF). Consigne : « tu prends le style, tu
l'améliores au besoin, et les cas d'usage qui ne sont pas couverts par le système de
paiement », car « on ne va plus partager un message unique aux élèves : l'app a son système
de paiement qui rappelle automatiquement ».

Ce fichier nourrit les compétences `annoncer-rewayah` et `voix-directeur` (lot SEC-0). Les
messages ne sont pas recopiés ici : ni numéro de téléphone, ni nom de personne, ni
coordonnée de paiement n'entre dans le dépôt.

## 1. Le style du directeur, tel qu'il est

- **Une adresse par public** : « Chers étudiants, » ou « Chers enseignants, ». Le même fait
  part en deux versions le même jour ; celle des enseignants ajoute ce qu'ils doivent faire
  (relancer leurs élèves, préparer la liste des participants, ajuster leur suivi).
- **Court** : deux à quatre phrases. Un fait, puis une demande.
- **Formules** : « Nous vous rappelons que… », « Nous vous informons que… », puis « Merci
  de… ». Fin possible : « Merci pour votre compréhension et votre réactivité. »
- **Dates entières** : jour de la semaine, date, année ; l'heure avec son fuseau.
- **Notes officielles numérotées** : « Note d'Information N°NN/2026/RA_STAFF » suivie du
  sujet. Les petits rappels ne sont pas numérotés.
- **Signature fixe** : RA_STAFF, le livre bleu, Rewayah Academy. Un seul emoji, celui de la
  signature ; un signe d'interdiction pour une règle qui ne se discute pas.
- **Religion, avec sobriété** : une invocation en fin de message pour les fêtes ; un rappel
  utile avant un jour important ('Arafah) ; une position claire quand il le faut (fin de
  l'année hégirienne : deux fêtes légiférées seulement, s'attacher à la Sunnah).
- **Ferme et à l'écoute** : la règle est dite nettement (présence obligatoire, dix minutes
  avant) ; l'élève qui a un souci avec son enseignant est invité à le dire en privé.

## 2. Ce que le secrétaire améliore dans l'application

| Avant (WhatsApp) | Dans l'application |
| :--- | :--- |
| Un message pour tout le monde, « pour certains » | Seulement aux personnes concernées |
| Deux publics | Élèves adultes, familles (enfants), enseignants, équipe : une version par public |
| Français seulement | La langue de chaque compte (arabe, français, anglais) |
| « Heure de Paris » | L'heure dans le fuseau de chaque lecteur |
| Coordonnées de paiement dans le message | Jamais dans une annonce : l'écran de paiement |
| Aucun geste | Un bouton quand il y a quelque chose à faire (voir le calendrier, écrire à la direction) |
| Numéro tenu à la main (le N°15 manque) | Numéro donné par le serveur |
| Report annoncé « jusqu'à nouvel ordre » | Toujours dire quand viendra la suite, ou qui la dira |
| Congé annoncé, programme laissé à l'enseignant | Dire quoi faire pendant le congé, et la date de reprise dans le calendrier |

Les mots passent par `mots-rewayah` (par exemple le mot employé pour « étudiants ») et la
signature par `marque-rewayah` : tant qu'aucune décision ne la change, la signature du
directeur reste.

## 4. Ce que le système de paiement ne couvre pas

Le rappel du paiement du mois n'est plus une annonce : le système de paiement le fait seul.
Restent à écrire par le secrétaire :

- congés et reprises, vœux, rappels religieux ;
- évaluations : convocation, consigne aux enseignants, report et nouvelle date ;
- une règle d'argent qui touche tout le monde (dans l'archive : « les congés ne sont pas
  payés ») : **à ne pas répéter telle quelle** tant que `A-HARMONISER-REGLES-ARGENT-ET-ARRET.md`
  n'a pas tranché ; le secrétaire le signale au directeur (niveau C) ;
- un moyen de paiement indisponible ou changé (dans l'archive : les liens de paiement
  « momentanément indisponibles ») : annonce aux seules personnes qui l'emploient ;
- qualité : horaires, régularité, comment signaler un souci en privé ;
- vie de l'application : panne, lenteur, nouveauté, changement d'horaire, nouvelle classe,
  place libérée, accueil d'une nouvelle promotion ;
- consignes aux enseignants seulement (relancer, préparer, saisir).
