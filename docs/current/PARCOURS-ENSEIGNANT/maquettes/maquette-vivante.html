    La file qui s'entrechoque

    L'arrivant tape la file ; chacun recule un peu moins que le précédent, puis tout se tait.

    La jauge d'eau

    Pour un envoi de fichier, un taux de présence, un compte à rebours.

    La bulle vivante

    Une seule masse, jamais coupée en deux. Elle se réveille au toucher, change de forme sans se répéter, puis se rendort.

    Les coins justes

    Deux règles : la courbe continue (pas un quart de cercle collé à une droite), et le rayon intérieur = rayon extérieur − marge.
