Vos questions du 19 novembre

Lu dans le code

Application Android et iPhone : faut-il migrer ?

Non. Même compte, mêmes données, même code. L'adresse web continue de marcher. La personne installe l'application une fois depuis la boutique ; ensuite les mises à jour arrivent seules. Durée : quelques semaines pour Android, plus pour iPhone (validation d'Apple, compte développeur payant).

Lu dans le code

La mise à jour sur le web

Aujourd'hui : un bandeau « nouvelle version prête » avec « Recharger », sans « plus tard » ni croix, et il pousse l'écran vers le bas. À faire : « Maintenant » ou « Plus tard », puis mise à jour toute seule à la prochaine ouverture.

Lu dans le code

Le bandeau jaune qui décale l'écran

Vous avez raison : tous les bandeaux sont posés au-dessus de la page, donc ils la poussent. « Messages pas en direct » ne peut pas se fermer. À faire : un avis qui flotte par-dessus, aux couleurs de la marque, sans rien déplacer.

Lu dans le code

Glisser à gauche ou à droite

Ce n'est pas le langage. Ces gestes n'ont jamais été construits : aucun glissement sur une ligne, aucun glissement pour répondre, et le retour par glissement est désactivé dans la version web. C'est faisable.

Cause non trouvée

« Tout sélectionner » au moindre toucher

Toute l'application est sélectionnable d'un seul bloc. Je n'ai pas trouvé le réglage qui déclenche le menu sur un simple toucher : à reproduire sur votre téléphone, puis à limiter aux vrais textes.

Lu dans le code

L'écran du code d'un membre invité

L'accueil de l'équipe n'est pas caché derrière l'écran du code : la porte est tenue par la navigation et par le serveur, qui ne donne rien avant la validation. L'éclair que vous voyez reste à expliquer ; il ne livre pas de données.

Pas de vidéo possible : entendu. Je chercherai dans le code les deux sorties que vous citez (quitter la messagerie, quitter un dossier) et la correction déjà faite ailleurs, pour appliquer la même.

Votre décision

Riwayat et contrat

Le nom est عقد معلم. Riwayat : « J'ai une ijaza dans les dix lectures », « dans les sept lectures », ou « quelques lectures » avec le choix de celles maîtrisées. Demander un complément cochera d'office tout ce qui manque au dossier ; vous décochez ce que vous voulez.

Précision

« 7 jours », de quoi ?

Le candidat qui touche « Retirer ma candidature » par erreur pourrait l'annuler lui-même pendant 7 jours, sans vous écrire. Aujourd'hui, vous seul pouvez la rouvrir : 20 retraits, dont 13 encore fermés.
