# Registre des textes validés par le directeur

Règle du 07/11/2026 : **un texte ou une décision du directeur qui n'est pas dans le dépôt n'existe pas
pour les agents.** Si le directeur valide un texte ailleurs (artefact, Claude Docs, conversation), le
garde-cap le recopie ici le jour même, mot pour mot. Il y note la date, le lien d'origine et son statut.
Tout agent cherche ici avant d'écrire un texte légal, religieux ou contractuel.

La règle vient d'un incident du même jour. Le directeur se souvenait d'avoir validé le texte du cadre
religieux, mais personne ne l'a retrouvé : ni dans les 114 artefacts, ni dans Claude Docs, ni dans le
Drive, ni dans l'historique git. Il a fallu le réécrire.
