# Table des réglages de l'école

> **EN VIGUEUR par arbitrage de l'architecte pédagogique (12/11/2026), sur délégation du directeur. Le directeur peut corriger toute règle à tout moment ; une correction datée de sa part l'emporte.**
> **C'est la seule table des valeurs.** La charte, les scénarios, les évaluations et le moteur de suivi renvoient ici. Si un chiffre écrit ailleurs diffère, c'est cette table qui fait foi, et l'autre fichier est à corriger.
> **Règle du directeur (12/11/2026) :** l'architecture est fixe, les valeurs sont réglables par la direction.

**Comment lire la table.**
- **DÉCIDÉ (date)** : décision datée du directeur. La valeur ne change que sur une nouvelle décision datée du directeur.
- **ARBITRÉ** : valeur fixée par l'architecte le 12/11/2026 (raison dans `ARBITRAGES.md`). Elle s'applique ; la direction peut la changer.
- Une seule valeur par réglage. Le moteur de suivi (`MOTEUR-DE-SUIVI.md`) lit ces valeurs telles quelles ; ce qu'il précisait de plus y est entré le 12/11/2026 (partie 7).
