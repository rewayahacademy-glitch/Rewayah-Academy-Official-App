# Agents actifs

Panneau qui montre, pendant une session Claude Code, les agents qui tournent : titre, barre d'activité qui avance tant qu'ils travaillent, état, temps écoulé, étapes, dernière action, et les tokens lus et écrits (par agent, pour la session principale et au total).

La barre mesure l'activité (étapes du modèle) rapportée à l'agent le plus actif : le moteur ne connaît pas le pourcentage réel d'une tâche.

## Installer

```
/plugin install agents-actifs --marketplace rewayahacademy-glitch/Rewayah-Academy-Official-App
```

Répondre `y` pour ajouter le catalogue, puis choisir la portée « utilisateur » pour l'avoir dans toutes les sessions.

## Ouvrir

Le panneau s'ouvre au démarrage de la session. La commande `/agents` le rouvre.
