Rewayah Academy

De l'inscription à la proposition de classe

L'inscription et le suivi de votre demande s'effectuent dans l'application Rewayah.

Continuer dans Rewayah

01 / Rewayah

1. Ouvrir le parcours dans Rewayah

Le bouton d'inscription ouvre la connexion de l'application. Si aucun compte n'existe, l'application reprend le parcours vers l'inscription.

L'accès reste dans l'application existante; le site public ne crée pas de compte séparé.

02 / Rewayah

2. Examiner les propositions publiées

Les jours et horaires présentés sont des propositions publiées par l'administration. Vous pouvez consulter les options qui apparaissent dans le parcours.

Une préférence exprimée ne réserve pas une place et ne confirme pas une classe. Aucun enseignant ni compteur de places n'est présenté à cette étape.

03 / Rewayah

3. L'équipe traite les intentions

L'administration examine les intentions reçues et organise les classes selon l'offre et les possibilités disponibles.

Le site ne promet pas de délai de traitement non publié.

04 / Rewayah

4. Recevoir une proposition de classe

Une proposition de classe intervient après le traitement de la demande. Elle précise les informations à examiner avant toute confirmation.

Le prix, la devise, les taxes et les conditions applicables doivent être consultés dans le récapitulatif contractuel avant paiement.

05 / Rewayah

Pour inscrire un enfant

L'inscription d'un mineur est effectuée sous la responsabilité d'un tuteur adulte autorisé. Un enfant ne rejoint pas un cours seul.

Pour une question sur l'accès, contactez support@rewayahacademy.com.
