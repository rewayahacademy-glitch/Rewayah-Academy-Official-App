Pour chaque fichier, dans l'ordre

Ouvrir l'éditeur SQL de la base de test (gardez cet onglet ouvert à côté de celui-ci)

  1. Sur cette page, cliquez sur Copier le fichier du numéro surligné.
  2. Dans Supabase, cliquez dans la grande zone de texte, puis Ctrl + A pour tout sélectionner et Ctrl + V pour coller (sur Mac : Cmd au lieu de Ctrl). L'ancien texte est remplacé.
  3. Cliquez sur le bouton vert Run en bas à droite (ou Ctrl + Entrée).
  4. Si une fenêtre d'avertissement parle d'une opération destructive (destructive operation), cliquez sur Run this query__DESTRUCTIFS__
  5. Attendez le message Success. No rows returned sous la zone de texte (quelques secondes pour les gros fichiers), puis cochez Fait ici et passez au suivant.

Si un message rouge « ERROR » apparaît

Arrêtez-vous là, ne collez pas le fichier suivant. Faites une capture d'écran du message et envoyez-la-moi. Chaque fichier s'installe en entier ou pas du tout : un fichier en erreur n'a rien écrit. Chaque fichier est protégé contre les fins de ligne que Windows ajoute au copier-coller.
